# Hiral’s Lab

**[Explore the live portfolio ↗](https://hiral13choksi.github.io/hirals-lab/)**

*The Museum of Unfinished Questions* is my interactive portfolio for applied data science, machine learning, and computer vision. Step into the 3D lab for a guided tour, or jump straight to the featured projects for a quick look at what I built and how I tested it.

## Featured work

| Exhibit | What it explores |
| --- | --- |
| **MyCoast Flood Depth Estimation** | Estimates floodwater depth from street photos using computer vision and checks those estimates against field measurements. |
| **ClariHealth AI** | Explores how a conversational assistant could help patients navigate common tasks in a patient portal. |
| **Lumera** | Helps users explore research evidence about rare diseases. |

The site also features coastal high-tide forecasting, product-length prediction from the Amazon ML Challenge, and an interactive tobacco policy dashboard.

## Run locally

From the repository root, run:

```bash
python -m http.server 8000
```

Open [localhost:8000](http://localhost:8000). The site uses HTML, CSS, JavaScript, and Three.js, and is hosted on GitHub Pages. See [CREDITS.md](CREDITS.md) for asset and library credits.
